# 標籤管理

## 第一步永遠是 `gmail_list_labels`

`gmail_modify_labels` 需要的是 **label ID**，不是名稱。每個任務開始時：

1. 呼叫 `gmail_list_labels`
2. 建立「名稱 → ID」對照
3. 之後所有操作都用 ID

## 系統標籤（ID 固定，不可改名或刪除）

| ID | 意義 | 常見操作 |
|---|---|---|
| `INBOX` | 收件匣 | 移除 = 封存 |
| `UNREAD` | 未讀 | 移除 = 標為已讀；加入 = 標為未讀 |
| `STARRED` | 星號 | 加入 / 移除 |
| `IMPORTANT` | 重要 | 加入 / 移除 |
| `SPAM` | 垃圾郵件 | 不要自動加，誤判代價高 |
| `TRASH` | 垃圾桶 | 用 `gmail_trash_message`，不要直接改 |
| `SENT`、`DRAFT` | 寄件備份、草稿 | 不要修改 |
| `CATEGORY_PERSONAL` / `SOCIAL` / `PROMOTIONS` / `UPDATES` / `FORUMS` | 分頁分類 | 可移動信件到其他分類 |

自訂標籤的 ID 通常是 `Label_` 開頭的字串。

## 比對使用者說的標籤名稱

使用者說「客戶」，但既有標籤可能是「客戶/ABC」「Clients」「客戶專案」：

- 完全相符 → 直接用
- 部分相符或有多個候選 → 列出候選讓使用者選
- 找不到 → 告訴使用者**本工具組無法建立新標籤**，請他在 Gmail 建立後再執行

不要因為名稱「差不多」就自行選一個。

## 巢狀標籤

名稱中的 `/` 代表層級，例如「專案/2026/官網改版」。搜尋時用 `label:專案-2026-官網改版`（空格和 `/` 在搜尋語法中常寫成 `-`）；若搜尋不到，改用原名加引號 `label:"專案/2026/官網改版"`。

## 批次貼標流程

1. 用 gmail-search 找出符合條件的信
2. 列出數量和前 5–10 封樣本（寄件者、主旨、日期）
3. 超過 10 封依 gmail-safety 先確認
4. 逐封呼叫 `gmail_modify_labels`
5. 回報：成功幾封、失敗幾封（失敗的列出原因）

## 規則

- 移除使用者自訂標籤前先確認；加標籤可直接做
- 「移到某資料夾」= 加該標籤 + 移除 `INBOX`，先確認使用者是否要從收件匣移走
- 一封信可以有多個標籤，加新標籤時不要順手移除舊的
- 想讓規則對未來信件自動生效時，告訴使用者需要在 Gmail 設定「篩選器」，本工具組無法建立
