# 郵件串摘要

## 流程

1. 找到目標信件（gmail-search），取得 `threadId`
2. 呼叫 `gmail_get_thread` 一次讀完整串，**不要**逐封呼叫 `gmail_get_message`
3. 依 `internalDate` 由舊到新排序
4. 每封信清理內文（見下方）後再摘要

## 清理內文

長串信件每封都夾帶前面所有內容，必須先去除：

- **引用內容**：`>` 開頭的行；`On ... wrote:`、`於 ... 寫道：`、`-----Original Message-----`、`寄件者: ... 傳送時間:` 之後的整段
- **簽名檔**：`--` 之後、或連續出現職稱 / 電話 / 地址的結尾段落
- **免責聲明**：「本郵件含機密資訊」「CONFIDENTIALITY NOTICE」等段落
- **HTML 殘留**：只有 `text/html` 時去除標籤、樣式、追蹤像素

清理後如果某封信只剩「好的」「收到」「謝謝」，在摘要中合併成一句，不要逐封列。

## 摘要格式

```
📧 Q4 預算確認（7 封，10/28 – 11/03，參與者：你、王經理、財務部陳小姐）

結論
- 行銷預算從 200 萬調降為 180 萬（王經理 11/01 確認）

未決事項
- 差旅費是否另列 → 等財務部陳小姐回覆
- 你需要在 11/07 前提交修正版預算表 ← 王經理在等你

時間線（只列關鍵轉折）
- 10/28 王經理提出初版
- 11/01 決定調降
- 11/03 陳小姐問差旅費歸屬，尚無人回
```

## 判斷「誰在等誰」

- 串中最後一封是別人寄的、且含問句或要求 → **使用者要回**
- 最後一封是使用者寄的（`labelIds` 含 `SENT`）→ **在等對方**，標註已等幾天
- 使用者寄件地址以標頭 `From` 比對（透過 `in:sent` 的信可確認使用者自己的地址）

## 規則

- 摘要只寫信中有的內容，不推測意圖；不確定時寫「信中未明確說明」
- 人名用信中的稱呼；只有 email 時用 `@` 前面的部分
- 數字、日期、金額照原文，不要四捨五入或換算
- 串中有附件時，列出檔名，問使用者是否要讀（見 attachment-handling）
- 超過 20 封的長串：先給一段總結，再問要不要展開時間線
